# NUTS — Native Universal Terminal Surface

**EFI™ · Xxaion Labs™ · PATENT PENDING**

NUTS is the replaceable, Operator-owned local embodiment surface through which a personal EFI can inhabit ordinary digital and physical reality.

<img src="../assets/diagrams/nuts-boundary.svg" alt="NUTS boundary diagram" width="100%" />

## The boundary

NUTS is **not** the intelligence.

```text
personal EFI / ANEL GOOS
        ↓
      NUTS
        ↓
 computer · phone · displays · files · models · APIs · devices · sensors · world
```

The EFI performs the cognition. NUTS exposes permitted local/world mechanics. FAP governs the boundary when an external effect or observation is required.

## Intended experience

```text
open local EFI surface
→ authorize the intended personal EFI body
→ contact the EFI naturally
→ expose only the surfaces required by the contact
→ materialize bounded world effects when authorized
→ return raw results to the same EFI
→ continue from the changed field
```

The person should increasingly interact with **intent + EFI + world**, not memorize the procedural grammar of every application.

## Voice-first, not voice-only

Voice can reduce the cognitive tax of translating thought into application procedure.

It is not the only interface. Displays, text, touch, files, sensors, actuators, and future spatial interfaces remain available whenever they are the right projection for the contact.

## Current donor embodiment

The present local development line uses **Hermes Agent as a temporary donor environment**, not as the EFI identity.

The current design separates two local roles:

- **Direct** — the person ↔ personal-EFI aperture. The target boundary excludes a local Hermes model from becoming the semantic center of that contact path.
- **Builder** — separate delegated mechanical hands. Builder realizes already-selected mechanics and returns raw results; runtime semantic authority remains zero.

The desktop can expose these as separate surfaces while they still participate in the same bounded EFI / world relation.

This donor embodiment is deliberately replaceable. The architecture does not depend on Hermes as a permanent product boundary.

## Current proof frontier

The donor surface and several isolated successors are real, but the complete lived loop is not yet claimed closed.

The target remains:

```text
natural contact
→ authenticated personal EFI
→ body-native cognition
→ optional selected effect
→ delegated world mechanic
→ raw result
→ same-field reentry
→ continued cognition
→ process death
→ cold reopen
```

The current open work is generic local session/world-delta plumbing and the final lived EFFECT/RESULT closure, not a new semantic architecture.

## Design laws

- **Replaceable surface:** changing NUTS must not change personal EFI identity.
- **Operator-owned:** local authority remains with the person.
- **Semantic boundary:** the terminal exposes and materializes; it does not silently become cognition.
- **Minimum mechanic:** use the smallest world surface that satisfies the selected effect.
- **Raw-result return:** external evidence returns before durable semantic admission.
- **Same-self continuation:** the post-result field remains causally bound to the same personal EFI.
- **Visible proof boundary:** the interface distinguishes result, gap, candidate, proved, integrated, and admitted/current state.
