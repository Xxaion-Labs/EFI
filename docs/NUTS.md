# NUTS — Native Universal Terminal Surface

**EFI™ · Xxaion Labs™ · PATENT PENDING**

NUTS is the replaceable, human-owned local embodiment surface through which a personal EFI can interact with ordinary digital and physical reality.

<img src="../assets/diagrams/nuts-boundary.svg" alt="NUTS boundary diagram" width="100%" />

## The boundary

NUTS is **not** the intelligence.

```text
personal EFI
    ↓
   NUTS
    ↓
computer · phone · displays · files · models · APIs · devices · sensors · world
```

EFI supplies cognition. NUTS exposes permitted world surfaces. FAP governs consequential external EFFECT / RESULT exchange.

## Intended experience

A mature NUTS interaction should feel simple:

```text
open the local EFI surface
→ authenticate the intended personal EFI
→ communicate naturally
→ expose only the required world surface
→ materialize an authorized bounded effect
→ return the raw result
→ continue from the changed field
```

The person should increasingly interact through **intent + EFI + world**, not memorize the procedural grammar of every application.

## Voice-first, not voice-only

Voice can reduce interface friction, but it is not mandatory.

Text, touch, displays, files, sensors, actuators, accessibility interfaces, and future spatial interfaces remain available whenever they are the right projection.

## Design laws

- **Replaceable surface:** changing NUTS must not change personal EFI identity.
- **Human-owned authority:** local consequential authority stays upstream with the person.
- **No hidden second mind:** the terminal exposes and materializes; it does not silently become cognition.
- **Minimum mechanic:** use the smallest world surface required by the selected effect.
- **Raw-result return:** external evidence returns before durable semantic admission.
- **Same-self continuation:** post-result cognition remains causally bound to the same personal EFI.
- **Visible proof boundary:** interface polish never substitutes for cognition or continuity proof.

## Public proof frontier

The public architecture is released. The complete lived general loop remains an open proof boundary:

```text
natural contact
→ personal EFI cognition
→ optional authorized effect
→ world mechanic
→ raw result
→ same-field continuation
→ process death
→ cold reopen
```

Private implementation machinery stays private until a reproducible public release is deliberately packaged.
