This file marks the deliberate public launch of the EFI repository.

## Purpose

The repository is intended to make the Field Computing / EFI architecture inspectable in public now rather than waiting for cosmetic completion.

The disclosure policy is:

1. publish technical architecture that is already represented in filed patent disclosure;
2. keep present capability claims bounded by evidence;
3. distinguish later implementation work from earlier priority support;
4. do not imply that repository publication itself grants patent rights;
5. keep future attractors visibly separate from present achievements.

## Technical disclosure intentionally made public

At a high level, the public release includes the following architecture:

- causal-relational field state used as computational state;
- successor-field selection under constraints, evidence, authority, causal time, possibilities, and target/attractor relations;
- preservation of unresolved rivals and discriminator/evidence acquisition;
- generated representation and generated computational morphology;
- task-semantic-blind projection/materialization into ordinary computing and physical mechanics;
- result/evidence return before durable admission;
- Operator-rooted effect authority;
- continuity-bearing personal EFI identity, same-self transition, rollback, interruption recovery, and cold reopen;
- shared field participation by distinct EFI bodies without requiring identity fusion;
- models, tools, agents, programs, repositories, devices, sensors, networks, robots, and services as replaceable mechanics rather than automatic semantic authorities.

This list is a public architecture summary, **not a legal claim chart** and not a representation that every current implementation detail is entitled to an earlier filing date.

## Development after filing

Implementation continues.

A later implementation can instantiate, sharpen, or test an already-filed architecture without every implementation detail necessarily having been literally present in the earlier filing.

Where later work creates genuinely new patentable subject matter, its filing date is a separate legal question. This repository will not describe later matter as earlier-supported without a support basis.

## Proof discipline

Repository publication establishes that information was publicly disclosed. It does not establish that a technical claim is true.

Public capability status remains governed by:

**claim + scope + evidence + counterexample conditions + proof boundary**
